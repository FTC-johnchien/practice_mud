📜 序章 ‧ 盲目星蝕

天寶末年，九曜逆行，青雲觀後山封印萬載的太陰古塚傳來如巨獸心搏般的悶響。腥羶腐朽的死氣混合著天外不可名狀之囈語，自深不見底的玄陰幽穴中蔓延而出……

掌門真人羽化前以精血書就泣血符書：「天外盲目癡愚之星神不可窺探……古塚深處，埋藏著初窺群星而徹底發狂的太陰古仙遺蛻……若任其破土，億萬生靈將淪為無神死肉……」

作為青雲觀最後的真傳，你手握辟邪青銅古劍，率領五名同門步入古塚石階。青苔石門在你身後轟然閉闔，深淵幽冥中，數雙散發詭異磷光的瞳孔悄然睜開……

二、半即時戰鬥與三態資源

隊員依行動軸自動攻防，點選隊員可釋放絕學。符道消耗 真元 (MP)，力士受擊積累 怒氣 (Rage)，刺客平攻獲取 連擊點 (Combo)。

🧠
三、道心 SAN 與走火入魔

SAN 歸 0 進入 走火入魔 (傷害+100%、自殘 15%、40% 背刺隊友)；可施符 [施符鎮魔] 凍結失控；計數滿 100% 將異變為敵方 Boss，討伐可剖出【道核】傳承其生前絕學！

☯️
四、陣法靈威與公共行囊
