# 🌌 遊戲玩法與世界觀架構 (Gameplay & Lore Overview)

> **閱讀時間**：約 4 分鐘  
> 本文件介紹《道祖是克蘇魯》的克蘇魯暗黑修仙世界觀、核心玩法循環、道基體系與雙軌切換架構。

---

## 🌒 一、世界觀設定：太陰萬劫 ‧ 克蘇魯暗黑修仙

### 1. 核心背景
本遊戲世界觀取材自克蘇魯克系恐怖與東方古典仙俠的碰撞：
- **天道異化**：修仙者千辛萬苦所追求的「飛升」與「天道」，本質是不可名狀天外古神散播的寄生菌絲。修為越高，道心遭受的異化侵蝕越嚴重。
- **道心理智 (SAN 值)**：所有修士皆持有「道心理智值（Sanity）」。面對不可名狀之神魔、邪法煞氣或服用異化靈丹時，道心將遭受衝擊。SAN 值過低將引發道心瘋狂、幻覺低語，甚至導致走火入魔。
- **穿越者的唯物錨點**：主角身懷異界穿越者的現代思維記憶。在道心即將崩潰之際，能透過「物理法則」、「程式邏輯」與「唯物辯證」將不可名狀的煞氣強行降維封裝，穩固道基！

## ☯️ 二、雙軌切換機制 (Dual-Mode System)

遊戲最大特色在於融合了兩種截然不同的遊戲形態：

```
       ┌────────────────────────────────────────────────────────┐
       │                   道祖是克蘇魯 遊戲迴圈                   │
       └────────────────────────────────────────────────────────┘
                                   │
         ┌─────────────────────────┴─────────────────────────┐
         ▼                                                   ▼
┌─────────────────────────┐                         ┌─────────────────────────┐
│     【城鎮 MUD 模式】     │                         │    【地牢 DRPG 模式】     │
├─────────────────────────┤                         ├─────────────────────────┤
│ • 桃源村 / 墨竹山外圍     │      踏入地宮 / 礦坑     │ • 墨竹山礦坑 / 太陰古塚    │
│ • 文字描述、沉浸氛圍     │ ──────────────────────> │ • 第一人稱 3D 靈境視口    │
│ • NPC 交流、道侶招募     │                         │ • 走格子、暗黑迷霧探險    │
│ • 貨棧補給、法寶強化     │ <────────────────────── │ • 機關陷阱、寶箱棺槨      │
│ • 打坐調息、回滿狀態     │     沿向上石階 (leave)    │ • 半即時小隊回合戰鬥      │
└─────────────────────────┘                         └─────────────────────────┘
```

1. **城鎮模式 (Town MUD Mode)**：
   - 以傳統文字 MUD 的細膩筆觸呈現世界，右側配備直觀的城鎮 NPC 與出口操作面板。
   - 負責戰前準備：購買辟邪靈茶與金創藥膏、招募夥伴、換裝、調整陣法與存檔。
2. **地牢模式 (Dungeon DRPG Mode)**：
   - 踏入礦坑或古塚後，介面無縫切換為第一人稱 3D 透視走廊與雷達迷宮。
   - 每次移動檢定遇敵危險率，隨時可能遭遇異化魔物，戰況緊張刺激。
   - 探索完畢必須尋找「向上石階（`<`）」方能成功將戰利品帶回地表。若在深處全滅，將蒙受慘痛代價！

## 👥 三、小隊、陣法與道基體系

### 1. 滿編 5 人小隊編制
冒險隊伍由主角（道主）帶領 4 名夥伴組成，嚴格區分為三大站位：
- **前衛 (Front Row, 2 人)**：主坦與先鋒（如鐵牛、主角），承受近戰主要攻擊，具備仇恨加成與高根骨減傷。
- **中衛 (Middle Row, 1 人)**：遊俠與敏捷刺客（如燕青），進可攻退可守，擅長破防削韌與暴擊。
- **後衛 (Back Row, 2 人)**：法修、符師與醫道修士（如凌霜、墨衍），負責大範圍道法轟擊、群體治療與驅邪祛煞。

### 2. 道基五維屬性 (Five Pillars)
生靈的全部攻防數值皆由道基五維推導，絕不硬編碼：
- **體質 (Constitution)**：決定生命氣血上限（HP）與受創韌性上限（Max Poise）。
- **真元 (Essence)**：決定真元法力上限（MP）與道術威力。
- **神識 (Spirit)**：決定法術穿透、暴擊機率與道心抵抗（SAN 防禦）。
- **根骨 (Bone Structure)**：決定物理防禦、招架減傷與格擋成功率。
- **身法 (Agility)**：決定攻擊速度、閃避機率與戰鬥行動槽（ATB）推進速率。

### 3. 古仙陣法系統 (Formations)
小隊可啟用多種上古戰陣（如九宮八卦陣、北斗七星陣、玄天絕殺陣）：
- 陣法賦予全隊被動攻防增益（如身法提升 15%、全抗性 +10%）。
- 陣法精確調控前中後衛的仇恨吸引倍率，確保脆弱的後衛修士受到妥善護持。

## ⚔️ 四、核心戰鬥特色概覽

1. **半即時 ATB 輪詢**：戰鬥絕非死板的你一刀我一刀，而是依據「身法速度」各自推進冷卻槽。
2. **罡氣削韌（Poise）**：所有敵人均持有「罡氣韌性條」。當玩家施放重擊或破防戰技將韌性打空時，敵人將進入數秒的「破防虛弱」狀態，受到極大傷害加成！
3. **九大五行相生相剋**：傷害區分為物理（斬擊/鈍擊/穿刺）與道法（金/木/水/火/土/風/陰煞/陽光）。當敵人具備特定抗性時，傷害將被折減；若抗性超過 100%，甚至會觸發吸收逆流回血！

## 🚀 五、未來世界觀與玩法現代化演進規劃 (Gameplay Roadmap & Modernization)

為使《道祖是克蘇魯》邁向兼具深度、穩定性與現代沉浸手感的長線營運型單機／在線架構，規劃以下四大未來演化方向：

### 1. 現代遊戲規劃 (Modern Gameplay Pillars)
- **十二時辰晝夜更迭與微氣候生態**：
  - 引入子丑寅卯時辰循環：子夜陰煞暴漲，特定妖邪（如夜叉、陰兵）攻擊狂暴化並刷新稀有掉落；白晝陽氣充盈，客棧調息效率加成。
  - 動態天候（濃霧、陰雨、紫雷）：濃霧狀態下地牢雷達視野半徑由 3 步縮減為 1 步，雷雨時水火靈氣波動、雷法傷害提升 25%。
- **道心異化深淵博弈 (Sanity Breakdown & Eldritch Sight)**：
  - 突破傳統 RPG 僅將 SAN 值視為懲罰條的框架；SAN 值低於 30% 時啟動「不可名狀靈視」：戰鬥介面產生低語幻聽與視界畸變，但能揭露地牢隱藏的暗室古碑與太古神兵！
- **動態世界突發事件 (Dynamic World Invasions)**：
  - 安全區動態失守：一定週期觸發「百鬼夜行魔潮」，若玩家未在期限內完成前哨討伐，新手村客棧將暫時失去安全區調息能力。

### 2. 穩定性與數值平衡防禦 (Stability & Balance Defense)
- **非線性邊界衰減公式 (Diminishing Returns Guard)**：
  - 針對身法閃避（Dodge）、根骨格擋（Block）與暴擊率（Crit）引入雙曲正切或平滑飽和曲線 $\text{Rate} = \frac{x}{x + K}$，嚴格鎖定上限（如閃避硬上限 75%），杜絕後期數值堆疊導致「100% 絕對無敵」的架構性崩潰。
- **仇恨脫戰與動態彈性難度 (Dynamic Threat & Anti-Exploit)**：
  - 首領怪導入風箏抑制與仇恨鎖定，防範利用進出房間或走位死角進行零風險磨血。

### 3. 操作效率與玩家流體驗 (Player Flow & Efficiency)
- **雙態戰術預設組 (Tactics & Formation Presets)**：
  - 提供玩家一鍵切換「地牢省藍摸金預設」與「首領全力爆發預設」，自動切換 5 人小隊的技能 Stance 與 Gambit 規則鏈，大幅降低微操負擔。
- **智能戰鬥倍速與精準跳過 (Combat Speed Multipliers)**：
  - 支援 1x、2x 播放速率，已通過之已知迷宮清怪支援一鍵「神識推演（快速結算）」。

### 4. 可擴充性與長線內容架構 (Extensibility Architecture)
- **隨機古神詞綴體系 (Procedural Affix System)**：
  - 怪物與戰利品武器支援字綴動態複合（如 `【腐爛的】+【太陰附骨】+【玄鐵重劍】`），由 JSON 宣告前綴後綴庫，無需新增實體 Java 類別。
- **奇遇分支事件樹 (Encounter Decision Trees)**：
  - 地牢古碑事件支援多重選擇（「叩首參拜 (消耗 SAN / 獲得心法)」、「拔劍摧毀 (觸發惡靈 / 獲得靈石)」），100% 資料驅動解析。
