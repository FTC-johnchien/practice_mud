# Gemini Code Review & Suggestions

## 主題：選單 (Menu) 系統重構與 UI 規劃 (參考 DQ / FF 系統)

針對你提出的「選單」視窗重構計畫，這是一個非常棒且符合經典 RPG (DQ / FF / 浪漫沙加) 體驗的改動。將現有的「狀態」升級為統一的「主選單 (Main Menu)」，並採用左側導覽、右側內容的固定佈局，能大幅提升玩家的操作體驗與未來功能的擴充性。

以下是針對你提出的幾點規劃，我給出的建議與分析：

### 1. 裝備畫面的 5 人直排顯示 (5 Column Layout)
**你的提議**：隊伍最大 5 人，是否將資訊以直排的方式呈現，放最多 5 排？包含裝備、被動功法、屬性與 buff。
**在 1600x900 / 滿版外框下的最新評估 (重大好消息！)**：
*   **原本的空間瓶頸完全解除**：原本在 1160px 寬度時，扣除左側導覽後每人僅約 170px，容易造成文字折行與字體縮小的顧慮。
*   **1600px 寬度下的尺寸計算**：
    *   左側功能導覽列：佔用約 `220px`。
    *   右側主要內容區：擁有極其寬裕的 `1340px ~ 1380px`。
    *   5 人直排寬度：**每位角色可分得高達 `260px ~ 270px` 的寬度！**
*   **排版效果**：在 260px 的直欄中，配合 **13px ~ 14px 字體**，完全能非常優雅地放下一位角色的完整直立卡片：
    1.  頂部：角色頭像、#1~#5 編號、姓名、職業與等級。
    2.  裝備欄（7 格）：主手、副手、頭部、胸甲、鞋子、飾品1、飾品2。名稱可完整顯示不被截斷。
    3.  被動功法欄（4 格）：Weapon、Parry、Dodge、Force，帶有品階色彩與啟用狀態。
    4.  屬性面板：基礎點數 + 裝備加成（例如 `力量 25 (+8)`，綠字清清楚楚）。
    5.  Buff / Debuff 區塊：狀態圖示與持續時間。
*   **結論**：**完全支持你最初的「5 人直排」構想！** 在 1600x900 規格下，5 直排能呈現出極具震撼力的「全隊紙娃娃點將台」氣勢，玩家不需要頻繁換頁，一眼就能掌握 5 名隊員的所有裝備與功法！

### 2. 「戰術方針」的獨立性 (Gambit 系統)
*   確定採用 FFXII 的 **Gambit** 優先序規則鏈（條件 ➔ 目標 ➔ 技能 ➔ 開關）。
*   在 1600x900 的高度與寬度下，Gambit 規則列表可展開寬達 800~1000px 的條列式面板，搭配「上移/下移」、「快速切換條件」下拉選單，操作空間極其充裕。
*   **確認作為左側主選單的一級獨立入口**。

### 3. 裝備替換的子視窗與數值比較 (Equipment Child Window)
*   **操作流程**：在 5 人直排中點選某角色的「主手」裝備格，原內容區直接滑入/覆蓋「裝備挑選與比較子視圖」。
*   **兩欄式佈局**：
    *   **左欄 (約 55% 寬度)**：該部位符合條件的備選武器列表，單頁 20 項，支援分頁。
    *   **右欄 (約 45% 寬度)**：資訊與比較面板。
        *   上方：現有裝備 vs 選中裝備。
        *   中央：數值變化（綠字增益、紅字衰減，字體保持 14px 清晰呈現）。
        *   **關鍵機制**：顯示當前啟用的武器功法（若不相容則紅字警告將切換/失效）。
    *   點選「確認裝備」後立即發送指令，後端刷新資料後子視窗自動關閉，回到 5 人裝備直排總覽。

### 4. 視窗尺寸與字體規範 (固定 1600x900 / 滿版適配)
*   **字體大小**：嚴格鎖定在 **13px ~ 14px**（重要標題 16~18px），不再出現 < 12px 的過小字體。
*   **外框尺寸**：採用 `width: min(1600px, 96vw); height: min(900px, 94vh);`。
    *   在大螢幕下固定為大氣的 `1600px × 900px`。
    *   在筆電或較小解析度螢幕下則自適應為滿版安全範圍 (`96vw × 94vh`)。
*   **分頁規範**：單頁最大 20 筆。在 900px 的高度下，20 筆項目（每項高約 30~34px）能非常平順地擺放，下方保留 50px 給翻頁按鈕列與統計文字，完全不需要任何額外的 Scope Bar 捲動！

### 5. 各主功能分類與路徑
*   **道具**：可使用 (回復/Buff) / 任務 / 全部。
*   **裝備**：5 人直排總覽 + 槽位點擊觸發比較子視圖。
*   **技能&法術**：可使用 (探索中可用) / 主動 / 全部。
*   **角色**：5 位隊員頁籤切換詳細數值。
*   **隊伍**：隊伍名冊編號調整 (#1~#5 上移/下移)，與 5x3 戰陣幾何座標解耦。
*   **陣法**：戰陣盤 (5x3 站位與加成) / 典籍庫 (20 筆/頁，人數頁籤)。
*   **戰術方針**：隊員 Gambit 規則鏈編輯。
*   **系統**：存檔 / 讀檔。

### 總結
尺寸提升到 1600x900 / 滿版適配，搭配 13-14px 字體，讓原本受限的排版限制完全解放。5 人直排的裝備大畫面在 1600px 下將會非常壯觀且直觀。
