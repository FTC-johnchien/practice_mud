# Gemini Code Review & Suggestions

## 主題：選單 (Menu) 系統重構與 UI 規劃 (參考 DQ / FF 系統)

針對你提出的「選單」視窗重構計畫，這是一個非常棒且符合經典 RPG (DQ / FF / 浪漫沙加) 體驗的改動。將現有的「狀態」升級為統一的「主選單 (Main Menu)」，並採用左側導覽、右側內容的固定佈局，能大幅提升玩家的操作體驗與未來功能的擴充性。

以下是針對你提出的幾點規劃，我給出的建議與分析：

### 1. 裝備畫面的 5 人直排顯示 (5 Column Layout)
**你的提議**：隊伍最大 5 人，是否將資訊以直排的方式呈現，放最多 5 排？包含裝備、被動功法、屬性與 buff。
**在 1600x900 / 滿版外框下的最新評估 (重大好消息！)**：
*   **原本的空間瓶頸完全解除**：原本在 1160px 寬度時，扣除左側導覽後每人僅約 170px，容易造成文字折行與字體縮小的顧慮。
*   **1600px 寬度下的尺寸計算**：
    *   左側功能導覽列：佔用約 `220px`。
    *   右側主要內容區：擁有極其寬裕的 `1340px ~ 1380px`。
    *   5 人直排寬度：**每位角色可分得高達 `260px ~ 270px` 的寬度！**
*   **排版效果**：在 260px 的直欄中，配合 **13px ~ 14px 字體**，完全能非常優雅地放下一位角色的完整直立卡片：
    1.  頂部：角色頭像、#1~#5 編號、姓名、職業與等級。
    2.  裝備欄（7 格）：主手、副手、頭部、胸甲、鞋子、飾品1、飾品2。名稱可完整顯示不被截斷。
    3.  被動功法欄（4 格）：Weapon、Parry、Dodge、Force，帶有品階色彩與啟用狀態。
    4.  屬性面板：基礎點數 + 裝備加成（例如 `力量 25 (+8)`，綠字清清楚楚）。
    5.  Buff / Debuff 區塊：狀態圖示與持續時間。
*   **結論**：**完全支持你最初的「5 人直排」構想！** 在 1600x900 規格下，5 直排能呈現出極具震撼力的「全隊紙娃娃點將台」氣勢，玩家不需要頻繁換頁，一眼就能掌握 5 名隊員的所有裝備與功法！

### 2. 「戰術方針」的獨立性 (Gambit 系統)
*   確定採用 FFXII 的 **Gambit** 優先序規則鏈（條件 ➔ 目標 ➔ 技能 ➔ 開關）。
*   在 1600x900 的高度與寬度下，Gambit 規則列表可展開寬達 800~1000px 的條列式面板，搭配「上移/下移」、「快速切換條件」下拉選單，操作空間極其充裕。
*   **確認作為左側主選單的一級獨立入口**。

### 3. 裝備替換的子視窗與數值比較 (Equipment Child Window)
*   **操作流程**：在 5 人直排中點選某角色的「主手」裝備格，原內容區直接滑入/覆蓋「裝備挑選與比較子視圖」。
*   **兩欄式佈局**：
    *   **左欄 (約 55% 寬度)**：該部位符合條件的備選武器列表，單頁 20 項，支援分頁。
    *   **右欄 (約 45% 寬度)**：資訊與比較面板。
        *   上方：現有裝備 vs 選中裝備。
        *   中央：數值變化（綠字增益、紅字衰減，字體保持 14px 清晰呈現）。
        *   **關鍵機制**：顯示當前啟用的武器功法（若不相容則紅字警告將切換/失效）。
    *   點選「確認裝備」後立即發送指令，後端刷新資料後子視窗自動關閉，回到 5 人裝備直排總覽。

### 4. 視窗尺寸與字體規範 (固定 1600x900 / 滿版適配)
*   **字體大小**：嚴格鎖定在 **13px ~ 14px**（重要標題 16~18px），不再出現 < 12px 的過小字體。
*   **外框尺寸**：採用 `width: min(1600px, 96vw); height: min(900px, 94vh);`。
    *   在大螢幕下固定為大氣的 `1600px × 900px`。
    *   在筆電或較小解析度螢幕下則自適應為滿版安全範圍 (`96vw × 94vh`)。
*   **分頁規範**：單頁最大 20 筆。在 900px 的高度下，20 筆項目（每項高約 30~34px）能非常平順地擺放，下方保留 50px 給翻頁按鈕列與統計文字，完全不需要任何額外的 Scope Bar 捲動！

### 5. 各主功能分類與路徑
*   **道具**：可使用 (回復/Buff) / 任務 / 全部。
*   **裝備**：5 人直排總覽 + 槽位點擊觸發比較子視圖。
*   **技能&法術**：可使用 (探索中可用) / 主動 / 全部。
*   **角色**：5 位隊員頁籤切換詳細數值。
*   **隊伍**：隊伍名冊編號調整 (#1~#5 上移/下移)，與 5x3 戰陣幾何座標解耦。
*   **陣法**：戰陣盤 (5x3 站位與加成) / 典籍庫 (20 筆/頁，人數頁籤)。
*   **戰術方針**：隊員 Gambit 規則鏈編輯。
*   **系統**：存檔 / 讀檔。

### 總結
尺寸提升到 1600x900 / 滿版適配，搭配 13-14px 字體，讓原本受限的排版限制完全解放。5 人直排的裝備大畫面在 1600px 下將會非常壯觀且直觀。

# Code Review & UI/UX 重構規劃建議

> **文檔更新時間**：`2026-09-27 00:07 (UTC+8)`
> **主題**：探索舞台、戰鬥介面、隊伍 HUD 與 Footer Bar 之全域佈局重構建議 (字體規範、資源池擴充、冗餘清理)

---

## 概述與重構背景

在完成「功能選單 (Main Menu)」的 DQ/FF 模態化重構後，遊戲內的主功能（道具/裝備/技能/角色/隊伍名冊/陣法/戰術方針/系統存讀）已具備固定 1600×900 規格與單頁 20 筆上限之現代規範。

然而，外層日常操作的**「探索舞台 (Exploration)」、「戰鬥介面 (Combat)」、「隊伍 HUD (Party Dock)」與「底部工具列 (Footer Bar)」**仍殘留早期 MUD 泥巴過渡期的硬編碼尺寸與低解析度版面（文字多處為 9~11px）。

針對本次提出的 5 項核心問題，以下提出完整架構分析、重構思路與具體執行方案。

---

## 核心議題深度剖析與架構建議

### 1. 探索 / 戰鬥 / 選單 頁面整體佈局重構（解決字體 >= 13px 破版問題）

#### 破版根本原因
* 現有探索面板（城鎮 NPC 清單、客棧對話、方位羅盤）採用早期寫死的固定像素高度（例如行高 36px、按鈕文字 10px）。
* 當強制將字體提升至 `13px ~ 14px` 時，字元寬度、行距及按鈕 padding 增加，導致固定高度容納不下，產生折行破版、文字溢出與垂直被截斷。

#### 重構架構：響應式 Flex / Grid 流式舞台
主視窗採用現代主流的「左右雙欄舞台」經典佈局（總寬自適應 1280px ~ 1920px，基準 1600×900）：

* **左舞台：主視覺與探索/戰鬥交互區（佔比約 60%）**
  * **頂部場景資訊區**：
    * 地點名稱徽章（16px 粗體）+ 環境氛圍描述（13~14px，行高 `1.6`，舒適閱讀）。
  * **中間交互主體區（自動延展，取消高度寫死）**：
    * **方位羅盤**：擴大為清晰的 3×3 觸控/點擊盤（每格 48×48px，字體 13px 居中），亦保留鍵盤 WASD 零延遲移動。
    * **環境生靈 / NPC 清單**：改為彈性網格卡片（Grid / Flex-col）。NPC 姓名 14px 粗體、身份簡介 13px、右側操作按鈕（交談/買賣/招募）13px，高度由內容自然撐開。
    * **地面掉落物**：獨立條列卡片，字體 13px。
  * **底部隊伍狀態列**：整合為精簡的橫向/網格狀態卡（接第 4 點）。
* **右舞台：沉浸式 MUD 故事日誌與戰報（佔比約 40%）**
  * 字體嚴格規範為 `13px ~ 14px`，專注於傳達沉浸式的文字劇情、NPC 交流與戰鬥打擊反饋。
  * 移除內部混雜的功能按鈕，維持純粹平滑自動滾動（Auto-scroll）。
* **中央覆蓋層：功能選單 (Main Menu)**
  * 延續已完成之 1600×900 / 滿版適配 Modal，按 `C` 或 `ESC` 開啟，關閉後自然回到乾淨的探索/戰鬥舞台。

---

### 2. 徹底廢除「前衛 / 後衛 (Front / Back Row)」設定與顯示

#### 冗餘分析
* **歷史包袱**：最初無陣法系統時，採用了粗糙的二元前/後排切換開關（`party switch`、`FRONT/BACK`）。
* **現狀演進**：現已全面實裝 **Romance SaGa 式「5×3 戰陣盤」**（具備玄武位、青龍位等孔位座標，自帶精確 X/Y 幾何站位與陣眼屬性加成）以及**「出戰名冊順序 (#1~#5)」**。
* 前/後衛標籤已與 5×3 陣法重複，且造成玩家認知混亂。

#### 處置決策
* **前端徹底除役**：
  * 移除隊伍 HUD 上的「前衛/後衛」色塊徽章。
  * 移除角色狀態頁與裝備頁中的「`🔄 換位 (前衛/後衛)`」按鈕。
* **後端架構淨化**：
  * 戰鬥中受擊率與射程判斷，全面對齊 5×3 陣法站位孔位座標（X=0 前排、X=1 中排、X=2 後排）或隊伍出戰順序，廢除獨立的 `RowPosition` 狀態切換。

---

### 3. Footer Bar（底部列）極簡瘦身與重新設計

#### 現存重複功能盤點
1. **存讀檔按鈕**：頂部導覽列已有 `[存檔]`，選單內亦有完整的 `[系統]` 5 槽位命冊存讀。
2. **陣法 (F) 按鈕**：頂部列已有當前陣法名稱、靈威槽與奧義施展按鈕；選單內亦有 `5×3 戰陣盤` 與 `典籍庫`。
3. **虛擬方向鍵**：探索區正中央已有更大更直觀的 3×3 羅盤，實體鍵盤亦支援 WASD。
4. **探查 (I) / 休息 (R)**：已由場景地圖探索與選單「凝神吐納」完整涵蓋。

#### 重新設計方向
將 Footer Bar 高度從原本臃腫的 60px+ 縮減為 **32px ~ 36px 極簡常駐工具列**，把寶貴的垂直螢幕空間釋放還給地圖探索與戰鬥日誌：

* **左側核心捷徑**：
  * `[📜 功能選單 (C)]`
  * `[🎒 公共行囊 (B)]`
  * `[⚡ 終端控制台 (~)]`
* **右側操作指引 (Hint Bar)**：
  * `💡 WASD: 移動 ‧ C: 選單 ‧ B: 行囊 ‧ 數字鍵 1~5: 施展絕技 ‧ R: 凝神吐納`
* 其餘所有重複按鈕與方向鍵全面拔除，介面乾淨俐落。

---

### 4. 隊伍區塊整合至探索/戰鬥舞台，精簡為核心即時狀態

#### 現狀問題
* 目前隊伍 HUD 是在整個介面最底端橫跨一整條黑底，若僅有 1~2 人出戰，右側會留下大片尷尬的空黑。
* 單張卡片塞滿了職業名、前衛標籤、陣位加成條文、甚至詳細數值，導致字體被迫縮小到 8~9px，易讀性極差且與選單重複。

#### 精簡後的隊員即時卡規範（字體 13~14px）
隊伍成員卡只保留即時生存與資源狀態，不顯示冗餘的靜態文字：

```text
┌────────────────────────────────────────────────────────┐
│ #1 玄靈子  Lv.1            [🌿清心] [🛡️金鐘] (Buff圖示) │
│ ❤️ HP:  120 / 120   [====================]             │
│ ⚡ MP:   60 / 60    [====================]             │
│ ⚔️ SP:  100 / 100   [====================]             │
│ 🧘 SAN: 100 / 100   [====================]             │
└────────────────────────────────────────────────────────┘
```

* **版面整合**：
  * 將 1~5 位成員的精簡狀態卡作為探索/戰鬥舞台的底層附屬區塊（或並列於下方），隨出戰人數自動以 Flex 居中或 Grid 均分排列。
  * 角色更深度的五維道基、裝備換裝、主修功法挑選，一律引導至按 `C` 開啟功能選單查看，達到「即時介面精簡高效、管理介面深度完整」的專業分工。

---

### 5. 每個成員全面開放四資源並列：HP / MP / SP / SAN（雙主動技資源池）

#### 為什麼目前只有 HP / (MP or SP) / SAN？
* 早期架構採用了戰士 (Rage/SP) 與法師 (MP) 互斥的單一資源設計（`CombatResourceType`），傳遞給前端時被壓縮成單一的 `currentResource / maxResource`，導致戰士看不到真元、法師看不到戰氣。

#### 為什麼修仙 / 現代 RPG 必須四資源並存？
* **法武雙修的必然性**：
  * 後期任何修士（如劍修、體修、丹修）都會兼具法術與武學套路。
  * **⚡ 真元 (MP)**：五行法術、道家符籙、護體罡氣、領域神通消耗。
  * **⚔️ 戰氣 (SP)**：兵刃連攜招式、套路必殺、身法武技、近戰肉搏消耗。
  * 一名劍仙揮舞飛劍套路消耗 SP，施展「萬劍歸宗」大絕則消耗 MP，兩者絕不應互斥。
* **後端基礎健全**：
  * 後端 `PartyMember` 內部原本就已經同時定義了 `currentMp/maxMp` 與 `currentSp/maxSp`。
  * 僅需在 `DrpgStateDto` 中同時輸出 `mp, maxMp` 與 `sp, maxSp`，前端即可完整渲染四計量條（紅/藍/黃/綠），徹底解開限制。
