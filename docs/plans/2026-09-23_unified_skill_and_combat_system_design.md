# 全域統一技能與戰鬥動能系統設計白皮書 (Unified Skill & Combat Dynamics Design Document)

> **版本**：v1.0 (2026-09-23)
> **核心目標**：收斂文字 MUD 與 DRPG 雙模式技能系統，廢除歷史硬編碼與零散資源計數，建立「單一真相源 (Single Source of Truth)」、「HP/MP/SP 三槽資源模型」、「被動/主動/合擊/陣法四型態」與「WoW常用列 + DQ/FF抽屜 混合式 UI/UX」。

---

## 一、核心設計哲學與邊界界定

1. **角色為核心 (Character-Centric)**：
   - 技能歸屬於角色本身（主角來自 MUD 武學傳承與修煉，夥伴來自職業天生或領悟）。
   - 隊伍中施展技能不再受限於歷史原型殘留的 `party_skills.json`，只要角色學會並符合條件（冷卻、裝備、資源）即可自由施展。
2. **單一資料真相源 (Canonical Data Schema)**：
   - 所有技能（武器武學、職業特技、仙門法術、被動心法）維持統一的 `SkillTemplate` 規範，存放於 `data/global/skills/**`。
3. **戰術載具 (Tactical Vessels)**：
   - **陣法 (Formation)**：賦予隊伍全域陣法絕技（如八卦陣護盾、鋒矢陣長驅直入）。
   - **合擊 (Combo / Synergy)**：2~5 人組合大招，需要指定角色/職業存活、陣法與複合資源。

## 三、數值資源大收斂：HP / MP / SP 三槽模型

徹底淘汰各職業自立門戶的零散計數（戰士怒氣 Rage 0~100、盜賊連擊點 Combo 1~5 等），全系統角色統一為三條標準動態資源：

```
┌──────────────────────────────────────────────┐
│ [角色名]  Lv.12 蜀山劍俠 (前衛)              │
│ HP: [████████████████████] 850 / 850 (氣血)  │
│ MP: [████████████░░░░░░░░] 120 / 200 (法力)  │
│ SP: [████████░░░░░░░░░░░░]  45 / 100 (戰氣)  │
└──────────────────────────────────────────────┘
```

### 1. 資源定義與運作機制

1. **HP (Health Points / 氣血)**：
   - 角色生命。歸零時失去戰鬥能力（重傷/昏迷）。
   - 特定狂暴技能可消耗自身 HP 發動。
2. **MP (Mana Points / 法力 / 真元)**：
   - 仙門法術、神聖治癒、符咒結印消耗。
   - **靜態/長效資源**：戰鬥開始時繼承當前值；不因普攻自動增長；依賴打坐、丹藥、裝備回藍詞條或被動心法自然緩慢回覆。
3. **SP (Skill / Stamina Points / 戰氣勢能)**：
   - 物理武學、武器戰技、身法、爆發終結技消耗（上限固定為 100）。
   - **戰鬥中動態獲取 (Dynamic Combat Momentum)**：
     - 開場預設為 0（特定專精天賦可享有開場起始值）。
     - **普通攻擊命中**：+15 SP
     - **普通攻擊暴擊**：額外 +15 SP (共 +30)
     - **受到敵方傷害**：+10 SP
     - **成功招架 (Parry) 或 閃避 (Dodge)**：+20 SP
     - **戰意宣洩**：使用終結技或高級武學消耗 30~80 SP。

## 五、四步落實計畫 (Implementation Roadmap)

### Step 1: 資料模型重構 (Data Driven)
- `SkillTemplate.java`：
  - 增補 `skillType`: `ACTIVE`, `PASSIVE`, `COMBO`, `FORMATION`。
  - 資源消耗欄位收斂為：`cost: { "mp": 0, "sp": 30, "hp": 0 }`。
  - 被動技欄位增補：`enableSlot`: `DODGE`, `PARRY`, `FORCE`, `WEAPON_TECH` 等。
- `data/party/formations.json`：
  - 陣法資料補齊其對應之 `formationSkills`。

### Step 2: 戰鬥模型與動能簡化 (Engine Core)
- `PartyMember.java`：
  - 統一屬性為 `hp / maxHp`, `mp / maxMp`, `sp / maxSp` (上限 100)。
  - 移除殘留之獨立 `rage` 與 `comboPoints`。
- `DrpgCombatLoop.java`：
  - 實作戰鬥心跳中的 SP 動態積累公式（普攻命中、受擊、格擋、暴擊）。
  - 技能施展資源檢定與扣除邏輯統一由 `sp / mp / hp` 接管。

### Step 3: 合擊與陣法引擎解算 (Tactics & Combo Engine)
- 建立 `ComboResolver.java`：
  - 檢定小隊多人合擊條件（參與者存活、無失控狀態、各自身上 SP/MP 充足）。
  - 執行合擊時，原子化扣除各參與成員資源，並產生全隊聯合戰鬥日誌廣播。
- 陣法技能可用性解算：
  - 判定當前隊伍陣法是否啟動且陣眼健康，動態注入陣法大招。

### Step 4: 前端 UI 與技能抽屜升級 (Frontend Architecture)
- `party-hud-panel.js`：
  - 小隊 HUD 規範呈現 紅(HP) / 藍(MP) / 黃(SP) 乾淨三色條。
- `skill-drawer.js` & `battle-panel.js`：
  - 戰鬥面板提供 4~6 格常用推薦列。
  - 展開抽屜實作 5 大分類 Tab（武學/職業/法術/合擊/陣法）。
  - 合擊技條件達成高亮發光動畫與懸停需求提示。
