# 實施計畫：多武器普攻動態綁定、高級劍法套路切換與非人種族天然攻擊體系

## 1. 背景與動機
- 傳統 MUD 中玩家手持神兵利器，但戰鬥時卻可能被判定為赤手空拳張開血盆大口咬人或抓癢傷害。
- 玩家裝備不同兵刃（劍、刀、槍、斧、棍、錘、匕首、弓）時，應能自動切換對應門派基礎武學套路。
- 玩家習得高深劍法（如太極劍法、太陰幽冥劍法、天劍飛仙術）時，應能在角色狀態介面自由切換主力普攻套路。
- 遊戲中的非人生物（如野鼠、野狼、巨龍、殭屍）沒有裝備武器時，應依種族天生攻擊池（如爪擊、撕咬、甩尾、吐息）隨機施展多樣化招式。

## 2. 架構決策與實施方案 (Architecture Decisions)

### 2.1 武器與普攻套路動態綁定 (`SkillService.java` & `CombatService.java`)
- 戰鬥回合中動態讀取隊長裝備之武器類型（`weapon.getSubType()`）：
  - `SWORD` -> 基礎劍法（順勢一劈、中宮直刺、斜劍穿花）
  - `BLADE` -> 基礎刀法（力劈華山、迎風破浪、橫掃千軍）
  - `SPEAR` -> 基礎槍法（靈蛇出洞、霸王硬折弓、回馬槍）
  - `AXE` -> 基礎斧法（旋風開山、盤古開天、橫斬巨木）
  - `STAFF` -> 基礎棍法（掃堂疾風、金猴奮棒、毒蛇尋穴）
  - `HAMMER` -> 基礎鈍器（泰山壓頂、千鈞重墜、碎骨重錘）
  - `DAGGER` -> 基礎短匕（幽影背刺、割喉疾刃、靈狐突襲）
  - `BOW` -> 基礎弓術（開弓引月、流星追影、連環飛矢）
  - 空手（未裝備武器）-> 100% 保底套用 `basic_fist`（基本拳腳：直拳突刺、側身鞭腿、上勾拳、手刀）。
- 正確套用武器 14~22 傷害數值與武器名稱，拔除出戲的毫秒時間戳記。

### 2.2 高級武學套路專修與切換 (`PartyMember.java` & `PartyCommand.java`)
- `PartyMember` 增加 `enabledSkills` (`Map<SkillCategory, String>`)：
  - 記錄每個武器類型的指定主力武學套路。
- 擴充三套高級劍法標準 JSON：
  - `taiji_sword`（武當太極劍法：白鶴亮翅、順水推舟、仙人指路、流星趕月）
  - `taiyin_sword`（太陰幽冥劍法：陰魂泣血、白骨穿心、幽冥磷火、太陰蝕日）
  - `tianjian_sword`（天劍飛仙術：青鋒掠影、劍氣破霄、萬流歸宗、天外飛仙）
- 支援指令：`party enable <memberIndex> <skillId>`。
- 狀態彈窗（`C` 鍵）支援一鍵點擊切換當前主力普攻套路，並高亮標記當前主力套路；卸除武器後自動優雅回退為基本拳腳。

### 2.3 非人種族天然攻擊體系 (`RaceTemplate.java` & `BattleService.java`)
- 支援非人種族配置 `naturalAttacks` 權重攻擊池：
  - 野鼠：【試探抓擊】、【十字撕裂】、【快速輕咬】、【碎骨咬合】。
  - 巨龍：爪擊、撕咬、甩尾、重擊、龍炎吐息。
- 怪物沒有裝備武器時，不再固定使用死板的「揮拳毆打」，而是從天然攻擊池中依權重動態抽選招式。

## 3. 驗證與測試
- 單元與整合測試：`WeaponSkillBindingTest.java`、`MultiWeaponAndStanceTest.java`、`CombatFlowTest.java`。
- 自動化驗證持劍多劍法切換、多武器普攻映射、卸武空手拳腳回退，以及非人怪物種族攻擊池抽取。
