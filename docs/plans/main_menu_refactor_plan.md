# 主選單系統 (Main Menu) 重構實施計畫

> **狀態**：已批准，進入實施階段  
> **制定日期**：2026-09-26  
> **設計風格**：經典主機 RPG（勇者鬥惡龍 DQ / 最終幻想 FF / 浪漫沙加）固定多功能選單  

---

## 一、 核心視覺與尺寸規範

1. **選單外框**：
   - 採固定比例與滿版自適應：`width: min(1600px, 96vw); height: min(900px, 94vh);`。
   - 單一外框，不堆疊多層獨立 Modal；所有子功能與挑選視圖均於外框內部切換或滑入次層面板（Sub-view Overlay）。
2. **文字排版與字體大小**：
   - 全面鎖定標準字體為 **14px**（緊湊資訊最小允許至 **13px**，標題 16~18px），徹底根絕 < 12px 的過小字體。
   - 所有列表均具備彈性文字防截斷與省略號（Ellipsis）機制。
3. **分頁規格 (Pagination)**：
   - 通用單頁最大 **20 筆項目**（適用於道具、技能、陣法典籍庫、裝備挑選清單）。
   - 固定高度佈局，翻頁按鈕列與統計狀態固定於底部，完全消除無限滾動 Scope Bar。

---

## 二、 左側主功能架構 (Left Navigation - 8 大核心模組)

左側固定寬度約 220px 導覽列，右側為主要內容視口（約 1340px ~ 1380px）：

| 主功能 | 次層頁籤 / 功能定位 | 核心內容與互動規範 |
| :--- | :--- | :--- |
| **1. 道具** | [可使用] / [任務] / [全部] | 列表支援單頁 20 項分頁。可使用分回復與 Buff 類，提供即時隊員使用目標選擇。 |
| **2. 裝備** | 5 人直排全隊總覽 | 寬裕 260px × 5 直欄並列。每欄包含：角色頭像名冊、7 部位裝備槽、4 部位被動功法、基礎+加成屬性面板、當前 Buff 清單。<br>點擊裝備槽滑出「裝備候選與數值/武器功法 Diff 比較子視圖」。 |
| **3. 技能&法術** | [可使用] / [主動] / [全部] | 「可使用」對應探索地圖中可釋放技能；支援單頁 20 項分頁、資源消耗與冷卻標示。 |
| **4. 角色** | #1~#5 隊員分頁切換 | 詳盡個人面板：五維六道、氣血/真元/靈威、抗性、詳細點數分配與升階突破。 |
| **5. 隊伍** | 隊伍出戰名冊編號調整 | #1~#5 上移/下移排序調整。**明確與 5x3 戰陣盤幾何座標解耦**。 |
| **6. 陣法** | [戰陣盤] / [典籍庫] | 整合既有成果：戰陣盤沿用 5x3 浪漫沙加站位與孔位加成；典籍庫調整為單頁 20 筆與人數頁籤。 |
| **7. 戰術方針** | FFXII Gambit 規則鏈 | 條列式規則設定（優先級 1~N ➔ 觸發條件 ➔ 目標 ➔ 技能 ➔ 開關）。 |
| **8. 系統** | [存檔] / [讀檔] | 整合存讀檔槽位與自動存檔。 |
