## 一、 世界觀核心物理法則與本質（底層真相）

1. **星球本體與地質構造**：
   * **森羅星（黑羊之座，The Black Goat's Cradle）**：本體為外神「莎布·尼古拉絲」受創沉眠並收縮後的巨型卵鞘。
   * **偽地殼與血肉深淵**：地表是由數億年宇宙塵埃與古代工程師器材廢墟混合而成的「偽地殼」。越往地下深處，岩層越呈現纖維質的肉壁與血肉管道，核心則是包裹外神胚胎的羊水帶（卵白）。
   * **罡氣層（行星防逃逸電網）**：星球高空存在狂暴的「九天罡氣」，本質是萬年前工程師為防止失控生物兵器逃離星球而佈置的「高能電磁封鎖護欄」。
   * **神殞地陷與鯨落（天材地寶）**：地底卵鞘被工程師廢棄機器抽乾生命力後會灰燼化壞死，引發毀滅性局部地陷（修仙界稱「隕仙谷」或「葬神淵」）。壞死的古神細胞堆積在天坑底部被偽地殼吸收，在靈氣滋養下誕生血肉靈芝、硬化骨晶、高頻角質層等天材地寶。

2. **力量體系與文明本質**：
   * **靈氣 / 靈脈**：古代工程師開採地底外神生命力經設備散播到地表的次級能量；靈脈即是工程師採掘設施（分完好運轉的「活靈脈」與老化損壞的「死靈脈」）。
   * **修仙者（擬態修真）**：體內殘存工程師強殖兵器混血基因的原住民。修仙過程是將肉身向工程師原本想製造的完美生物兵器（降臨者）方向擬態：
     * *練氣/築基*：強化肉體適應靈氣，喚醒沉睡的強殖基因。
     * *結丹*：在體內凝練高濃度強殖兵器細胞核心（內丹）。
     * *元嬰/化神*：靈魂腦波強度足以與星球內部的工程師自動化網絡進行「神經元同步連結」，調動地脈設備展現搬山填海的「神通」。
     * *飛升真相*：體內強殖兵器基因徹底覺醒，肉身撕裂並完全轉化為無自我意識的「完美強殖裝甲降臨者」，隨即會觸發高空罡氣抹殺或被巨企捕獲回收。
   * **妖獸 / 妖修 / 法寶（退化的工程師遺產）**：萬年前工程師製造的基因兵器，體內設有需依賴高濃度靈氣維持的致命「飢餓鏈鎖」。隨靈氣匱乏演化出四條路線：
     1. *自我降級（退化流）*：關閉高頻粒子刀與重甲，退化為普通妖獸。
     2. *寄生混血（原住民混血）*：與人類繁衍，成為修仙者體內強殖基因的源頭。
     3. *機械擬態（法寶流）*：肉體主動與工程師廢棄零件長在一起，化為半機械半血肉的「上古法寶 / 魔器」，靠修士輸入法力騙取能源。

   * **母宇宙跨維度巨企（Mega-Corporation）**：

主角為穿越者，靈魂深處潛藏前世「千星聯合科技·高階戰術輔助思考晶片」。因穿越衝擊與無能源供應，開局時晶片處於**「深度休眠／未掛載」**狀態。主角一開始只把這當作一個殘酷詭異的修仙世界，必須透過**「眼見耳聞的違和細節」**累積認知衝擊，才能逐步啟動晶片外掛：

* **【Lv.0 凡俗迷霧期】（開局狀態）**：
  * **主角認知**：以為身處傳統魔道修仙宗門（黑煞宗），視走火入魔的骨刺、古怪的宗門法器為修仙界常態。
  * **晶片狀態**：完全沉睡。僅在主角遭遇致命危機或極度不合常理的機械/生化現象時，視網膜邊緣會閃過極其微弱的「雪花雜訊」或「耳鳴」。
* **【Lv.1 違和感與初次掛載】（接觸賽博走私品或黑煞晶髓）**：
  * **觸發條件**：親眼目睹「法寶」內部的精密齒輪/電路、接觸高純度「青玉髓」、或被「附魔電磁武器」近距離擦傷。
  * **晶片解鎖**：吸收微量煞炁能源完成開機。解鎖**【基礎生物掃描】**（看穿修士體內的強殖基因活性與污染度）與**【彈道/軌跡微積分預測】**（將低階修士的飛劍與符籙慢動作數據化）。此時大部分資料庫仍顯示為 `【權限不足 / 檔案損毀】`。
* **【Lv.2 靈脈與長生騙局】（深入宗門地底或接觸浮屠黑市核心）**：
  * **觸發條件**：親耳聽見靈脈底層的工程師活塞轟鳴、或目睹天機商會將修士內丹放入離心機提煉青玉髓。
  * **晶片解鎖**：修復部分前世企業記憶碎片。解鎖**【工程師設備接口協議（初級）】**與**【功法算法優化】**（用科學邏輯重構修仙功法，過濾煞氣雜質，避免長出畸變骨刺）。
* **【Lv.3 飛升真相與天外鐵幕】（目睹高階修士強殖化或遭遇荒坂特遣隊）**：
  * **觸發條件**：目睹結丹/元嬰修士失控變成「強殖裝甲生物兵器」，或與荒坂純白生化義體部隊交戰。
  * **晶片解鎖**：解鎖**【強殖基因圖譜逆向工程】**與**【黑客電子戰模組】**（可干擾巨企無人機與低階義體）。
* **【Lv.4 母神深淵與不可名狀】（接觸外洩卵白或外神密教）**：
  * **觸發條件**：直面地底血肉管道與外神卵白污染。
  * **晶片解鎖**：晶片算力超載，開啟**【理智防禦濾網（SAN值鎖定）】**，將不可名狀的外神低語強制降維編譯為可理解的物理波段。

## 四、 五維動態評級指標與全局環境變數（初始第 0 年）

### 1. 五維評級定義
* **軍事武裝（Force）**：正規武力、高階殺傷力、科技/法寶戰備（S ~ D）。
* **資源命脈（Economy）**：靈石、青玉髓、黑煞晶礦、糧食儲量與黑市現金流（S ~ D）。
* **認知維度（Cognition）**：對底層物理、工程師機械、外神真相或神經算法的掌握度（S ~ F / 混亂）。
* **生民水深（Living Index）**：轄區底層凡人與低階散修的生存狀態（**安居 / 苛刻 / 瀕潰 / 地獄**）。
* **異化污染度（Mutation Rate）**：門人與平民的強殖骨骼畸變、外神肉體異化或電子腦燒毀比例（**0% ~ 100%**）。

### 2. 全局動態環境變數（第 0 年基準）
* **地質沉降指數（神殞地陷）**：`10%`（偽地殼結構局部下陷，深層壞死正向表層傳遞）
* **外神卵白外洩濃度**：`5%`（巨企工程鑽探導致微細裂隙滲漏，外洩暫限於深淵天坑底部）
* **母神深空共鳴微度**：`0.00%`（莎布·尼古拉絲仍處深睡，深空尚未投下全新關注）
* **委員會合規審查警戒值**：`20%`（荒坂維持合規排他表象，千星隱密走私，未觸發仲裁線）

## 六、 世界線推演引擎執行規則（供 AI 運算遵循）

當接收到推演指令時，引擎必須嚴格執行以下**四階段運算**：

### 階段 1：行動驅動判定（Action Phase）
1. **死穴推力優先**：檢視各實體卡的「當前死穴」（如紫霄雷池大修、千星特工 KPI 催債、荒坂生化污染、墨家糧食見底），逼近死線的陣營率先採取高風險行動。
2. **地理相鄰限制**：任何陣營的常規軍事行動**只能對「直接相鄰」或具備明確空中/走私航線的勢力發動**，禁止跨越地圖憑空交火。
3. **成本與內耗折損**：發動行動必須消耗「資源命脈」，且其成效會受「內部矛盾」與「生民水深」牽制（如民怨高則後方易起義，內鬥深則指令執行打折）。

### 階段 2：空間地緣碰撞（Collision Phase）
1. 找出行動目標重疊的陣營，形成 **2~3 場核心戰役、外交博弈或走私危機**。
2. **嚴格套用五維相剋律**：
   * **電磁雷法（紫霄） vs 晶片軍火（賽博）**：大範圍 EMP 對義體與無人機具毀滅性癱瘓。
