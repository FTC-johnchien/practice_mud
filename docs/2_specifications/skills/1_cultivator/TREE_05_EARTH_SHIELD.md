3. **最佳排位**：前排一號位（重裝防衛者）。

## 🦴 三、常駐道骨插槽規格

- **插槽名稱**：**【大地同調脈】** (`bone_earth_resonance_vessel`)
- **插槽類型**：`SUB_SCHOOL_BONE` / `TALENT_CHIP`
- **被動常駐效果**：
  - 自身處於前排時，身後隊友受到的所有 AOE 與貫穿傷害降低 **25%**。
