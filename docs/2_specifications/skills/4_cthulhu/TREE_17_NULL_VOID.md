## 🧭 一、流派機制與戰術定位

1. **核心循環**：以【虛空碎裂·因果刃】實施微觀空間幾何撕裂，削韌並加深屬性傷害；以【太初鴻濛·記憶體洩漏術】在敵方體內種下不斷自我增殖的無底煞種，每回合傷害倍增，直至敵方無法施放消耗法力之招式。
2. **終結引爆**：以【萬法皆空·空指針崩解印】實施殘血斬殺，當目標氣血低於 18% 且破防時，直接強制 Core Dump 使其存在坍塌消散且免疫復活；施放天道大絕招【歸墟終末·格式化天劫】呼叫全場雷射抹殺，洗清全場所有 Buff、Debuff 與地形。
3. **最佳排位**：中排或後排極限終結斬殺位。
