# 🖥️ 純單機 DRPG 介面佈局與使用者體驗需求規格 (UI/UX Requirements)

> **文檔層級**：Level 1 — Requirements (需求與願景層)  
> **核心定位**：**純單機第一人稱地牢冒險 RPG (Single-Player DRPG)，PC 橫向優先、手機直向可自適應，融合 Wizardry / Etrian Odyssey 走格探索與 Knight & Dragon 選單戰鬥體驗**。  
> **關鍵界定**：**徹底除役 MUD 指令輸入框與文字房間移動；底欄文字日誌轉化為純唯讀的「克蘇魯文字情境敘事面板 (Narrative Event Log)」**。

---

## 📐 一、核心設計原則

1. **PC 優先，手機可用 (PC-First, Mobile-Adaptable)**：
   - **PC 橫向寬螢幕**：三欄式經典 CRPG/DRPG 常駐面板，全域資訊一覽無餘。
   - **手機直向窄螢幕**：上下堆疊 + 底部 Tab Bar + 抽屜式彈窗，單手即可點擊操作。
2. **純選單與按鈕交互 (Zero Command Typing)**：
   - 徹底移除任何打字輸入命令列。所有行為（探索走步、對話交易、施法技能、陣法調整）100% 透過視覺化按鈕、卡片與鍵盤快捷鍵（W/A/S/D、數字鍵 1~5、ESC）觸發。
3. **場景狀態機驅動的視圖切換 (State-Driven Viewport Switching)**：
   - **【狀態 A：城鎮營地中樞 (Town Hub)】**：設施卡片式選單（客棧調息、雜貨採購、鐵匠注靈、酒館編隊、地牢出征）。
   - **【狀態 B：地牢第一人稱走格 (Dungeon Exploration)】**：第一人稱 3D 透視視口 + 2D 走格迷霧雷達 + 火把狀態條 + 方向盤。
   - **【狀態 C：小隊獨立戰鬥擂台 (Battle Arena)】**：視口完整切換為戰鬥舞台（上方 5x5 敵方陣列、下方 5 人小隊、中間技能指令與 ATB 槽）。
   - **【狀態 D：全域彈窗管理 (Modals)】**：小隊公共行囊、裝備數值對比浮窗、夥伴功法樹、本地存檔管理。
4. **克蘇魯文字情境敘事面板 (The Living Narrative Log)**：
   - 雖然移除 MUD 打字指令，但**極具沉浸感的「文字敘事靈魂」100% 保留**！
   - 底欄為一行行向上滾動的唯讀敘事視窗，負責輸出石壁血肉撕裂聲、外神低語囈語、特工晶片代碼日誌與戰鬥暴擊高亮。

## 📱 三、手機直向自適應佈局（Knight & Dragon 風格）【待深入討論／演進目標】

> **版面架構演進說明**：現行實作版本先採左右雙主區（左主舞台切換＋左下小隊卡、右全高可收合日誌）過渡架構，三欄式與手機常駐底部 5 分頁導航列留待專題定案後推進（D1）。

- **頂部**：樓層名稱與 2D 縮略小雷達。
- **中上部**：第一人稱 3D 走廊視口（探索時）或 5x5 敵方血條陣列（戰鬥時）。
- **中下部**：前進/後退/轉向十字方向盤與互動動作鈕（探索時）或當前隊員技能招式列（戰鬥時）。
- **底欄**：滑動式文字情境敘事日誌（高度約 120px）。
- **底部常駐 Tab Bar**：【遠征】、【小隊】、【行囊】、【技能】、【存檔】。

## 🎨 四、視覺與特效需求

1. **暗黑地牢克系基調**：
   - 背景主色：極深黑褐色 (`#090a0f`)，營造被困於外神卵鞘地殼深處的壓抑感。
   - 靈境視口：以 Canvas / SVG 渲染第一人稱透視走廊，支援牆壁生物皮革紋理與血肉管道搏動微動畫。
2. **火把幽暗昏冥暈影 (Torch Darkness Vignette)**：
   - 光明度隨步進衰減，由明亮 (`BRIGHT`) 漸變為昏暗 (`DIM`) 與全黑 (`DARKNESS`)，全螢幕邊緣生成動態暗影暈影。
3. **戰鬥打擊反饋 (Combat Feedback)**：
   - 罡氣破防時螢幕劇烈震動與 Poise Break 特效；
   - 蓄力打斷時青藍色閃電電弧爆裂；
   - 連攜合擊（雙星合璧、三才混元、四象誅仙、天外合擊）彈出專屬流光大字。
