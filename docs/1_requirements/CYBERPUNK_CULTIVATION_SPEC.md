## 🧭 一、設計哲學：雙重疊影與代價轉換

每一項技能皆具備「三重維度」：
1. **修仙/克蘇魯表象**：東方古風符咒、道法、肉身法變或不可名狀異象。
2. **科技底層本質**：特工 AI 晶片執行的演算法、網路安全攻擊、義體過載或程式碼注入。
3. **實戰機制與代價**：消耗 MP、氣血、或對道心 SAN 值、過載熱量產生代價博弈。

## 🧩 二、四大技能體系與 16 項神通規範

### 體系一：網路安全與權限劫持類（對應：天道因果、精神契約與奪舍）

#### 1. 【偷天換日·轉煞移因訣】 (MITM Attack / 中間人流量劫持)
- **科技原貌**：建立隱蔽代理攔截竄改通訊，將惡意負載引流至替罪伺服器。
- **克蘇魯表象**：指尖溢出微光代碼靈絲，將原本鎖定在自身的古神注視或高階煞氣，搭接到敵方命盤上。
- **實戰機制**：施展高階招式時，將技能反噬或 SAN 值扣除代價 100% 轉嫁給目標敵人承受。

#### 2. 【太上太極·胎藏隔識印】 (Sandbox & Docker / 沙盒隔離)
- **科技原貌**：將不受信任的危險代碼隔離在虛擬化容器中執行，保護 Host OS 核心。
- **克蘇魯表象**：識海中構築由幾何代碼網格構成的封閉虛擬識海，外神囈語被困於網格中咆哮，無法侵蝕本體。
- **實戰機制**：短時間內絕對免疫精神衝擊、幻覺與「知見障」即死判定，但期間無法調用高階靈氣。

#### 3. 【萬念俱雜·三千紅塵濁浪潮】 (DDoS Flooding / 巨量阻斷攻擊)
- **科技原貌**：發送巨量垃圾封包塞爆頻寬與算力，造成服務器宕機。
- **克蘇魯表象**：將現代資訊爆炸雜念（股市代碼、演算法垃圾短片、都市噪音）混入煞氣灌入敵方修士識海。
- **實戰機制**：指向性控制技。迫使敵方心神過載陷入「走火入魔」硬直狀態，**中斷（Interrupt）**所有蓄力招式。

#### 4. 【周天易數·萬相破陣梭】 (Brute-force Cracking / 字典暴力破解)
- **科技原貌**：自動化高速遍歷所有密碼排列，突破安全閘門。
- **克蘇魯表象**：拋出數枚表面刻滿代碼與活體眼球的算籌，超越神識極限瘋狂自轉演算，撕裂護山大陣。
- **實戰機制**：無視目標護甲與罡氣韌性，造成真實貫穿傷害。

### 體系二：生物駭客與義體過載類（對應：肉身法變、異形同調與邪術改造）

#### 5. 【虛月逆行·皮相歸元法】 (Hot-patching Firmware / 韌體熱抽換)
- **科技原貌**：在系統運行中動態熱替換記憶體區塊，免重啟修復錯誤。
- **克蘇魯表象**：在血肉異化為利爪觸手戰鬥後，調用現代思維錨點，瞬間將畸變組織重組壓縮回光潔人類皮膚。
- **實戰機制**：戰鬥結束或危機時刻重置肉體「法變」時間，瞬間平息神識過載震盪，防止陷入精神萎靡 (CHAOS) 狀態。

#### 6. 【燃魂溯光·剎那千秋步】 (Neural Overclocking / 神經元超頻)
- **科技原貌**：強行突破硬體時脈頻率，以劇烈發熱與硬體損耗換取極致算力。
- **克蘇魯表象**：修士眼中泛起藍色螢幕故障光斑，血管暴起，在周遭所有人眼中化為一串殘影與幾何切面。
- **實戰機制**：大幅提升移動速度與攻擊迴避率，所有指令前搖歸零，但每秒持續扣除生命氣血（過載損傷）。

#### 7. 【萬蟲蝕命·煞種寄生禁】 (SQL / Shell Injection / 惡意代碼注入)
- **科技原貌**：將可執行代碼偽裝成資料輸入，在執行緒中奪取主機控制權。
- **克蘇魯表象**：將微縮異變肉質晶片或蠕動符文刺入敵人體內，利用其經脈自我複製。
- **實戰機制**：當敵人施展技能消耗法力時，符文同步引爆，將其消耗的法力轉化為對自身臟腑的爆破傷害。

#### 8. 【移花接木·太歲肉身契】 (Immunosuppressive Override / 生化義體排斥控制)
- **科技原貌**：使用免疫抑制劑與神經橋接器，將外來機械器官焊死在人體上。
- **克蘇魯表象**：斬下高階煞獸畸變器官（複眼、骨刺），以因果黑線縫合於斷肢處，壓制異物反噬。
- **實戰機制**：允許角色跨等級裝備「高污染級器官/法寶」，強制大幅降低排斥暴斃率。

### 體系三：光學渲染與認知介面類（對應：幻術、盲目度與知見干擾）

#### 9. 【太虛匿影·無貌欺天障】 (Glitch & Texture Failure / 頂點錯誤與貼圖丟失)
- **科技原貌**：引擎未載入貼圖，呈現紫色棋盤格穿透空間。
- **克蘇魯表象**：身體周圍空間出現像素掉落，天道外神視線判定此處為空白無實體區域。
- **實戰機制**：絕對隱匿狀態，脫離怪物仇恨列表，下次突襲必定暴擊。

#### 10. 【大智若愚·知見自盲術】 (Downsampling Pixelation / 畫素降採樣馬賽克)
- **科技原貌**：降低解析度以節省顯存，高模壓制為粗糙低模。
- **克蘇魯表象**：調用現代認知在視網膜覆蓋低解析度馬賽克，將前方蠕動流膿的外神解構成色彩模糊低多邊形。
- **實戰機制**：主動關閉視覺細節，降低 80% 面對高階古神時的神識精神衝擊（SAN 扣減），但短時間命中率下降 25%。

#### 11. 【虛妄重構·三世蜃樓鏡】 (Deepfake & Spoofing / 深度偽造與源地址欺騙)
- **科技原貌**：神經網路合成逼真視訊與虛假封包，誤導防火牆與監控。
- **克蘇魯表象**：以煞氣折射投影出三具具備實體生命體徵的幻影分身，分身手持虛假法寶衝鋒。
- **實戰機制**：召喚 3 個繼承本體 30% 氣血的虛影分身強制吸引仇恨，本體瞬移至後衛。

#### 12. 【逆熵之眸·量子觀測鎖】 (Frame-rate Locking / 幀率鎖定與物理引擎暫停)
- **科技原貌**：將物理模擬步長鎖死，防止物理對象穿模崩潰。
- **克蘇魯表象**：特工晶片超頻觀測，敵方飛劍與法術軌跡在空中被「按格定格」，如同抽幀動畫。
- **實戰機制**：敵方全體在 3 秒內攻擊速度與冷卻槽前進速度暴跌 70%，為小隊爭取喘息空檔。

### 體系四：底層架構與崩潰重置類（對應：天道法則破壞、維度坍塌與禁忌大招）

#### 13. 【萬法皆空·空指針崩解印】 (Null Pointer Dereference / 空指針例外崩潰)
- **科技原貌**：強制存取未初始化的記憶體位址，引發核心轉儲 (Core Dump) 與崩潰。
- **克蘇魯表象**：點出一道純黑指芒，抹除目標所依存的一條天地因果線，引發小範圍法則虛無。
- **實戰機制**：斬殺技能。當敵方生命低於 15% 且處於罡氣破防時，直接令其存在坍塌消散，免疫復活。

#### 14. 【九幽輪迴·硬體冷重啟】 (Hard Reboot / 核心強行斷電冷啟動)
- **科技原貌**：切斷主機板電源，清空所有暫存器狀態後重新開機。
- **克蘇魯表象**：主角捏碎心臟，以心頭熱血畫下重啟符文，短暫進入瀕死假死狀態，隨後生機重燃。
- **實戰機制**：致命傷觸發被動。免除死亡，清除全體負面 Debuff，以 30% 氣血在後排復甦（每場戰鬥限一次）。

#### 15. 【太初鴻濛·記憶體洩漏術】 (Memory Leak Flooding / 資源未釋放耗盡)
- **科技原貌**：不斷分配記憶體卻不釋放，最終擠爆 OS 記憶體資源引發 OOM 崩潰。
- **克蘇魯表象**：在敵方體內種下一粒不斷吸收其精氣神的無底煞種，隨時間幾何級數膨脹。
- **實戰機制**：終極 DoT。每回合傷害倍增，直至敵方無法施放任何需要消耗法力真元的招式。

#### 16. 【歸墟終末·格式化天劫】 (Format Drive / 磁區底層格式化零填入)
- **科技原貌**：執行 `dd if=/dev/zero`，將磁區所有數據全數歸零。
- **克蘇魯表象**：以特工權限強行向高空工程師遺留採掘設備發送廣播指令，引發全場雷射抹殺天劫。
- **實戰機制**：全體毀滅打擊，敵我無差別承受巨額傷害，洗清全場所有 Buff 與地形效果。
