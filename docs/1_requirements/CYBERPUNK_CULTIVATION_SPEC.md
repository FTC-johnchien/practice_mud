# ⚡ 賽博修仙與克蘇魯神話神通體系需求規格 (Cyberpunk Cultivation Spec)

> **文檔層級**：Level 1 — Requirements (需求與願景層·最高指導規格)  
> **核心本質**：**現代穿越者以冷定理性與程式邏輯，對不可名狀天道進行 Debug、權限劫持、降維封裝與爽快砍殺**。  
> **體驗權重原則 (The 85/15 Rule)**：**85% 核心體驗為爽快地牢砍殺刷寶與 Build 構築，15% 為非侵入式 (Non-Intrusive) 世界觀解密**。  
> **呈現準則 (Option C)**：**【仙俠先行 × 底層真相揭示】**。所有神通在 UI 介面、技能欄位、動作列一律以東方仙俠風格命名；懸停與特工加載度突破（>70%）時，揭示底層科技、代碼、工程師指令或外神血肉原貌。

## 🧭 一、設計哲學：雙重疊影與四維契約

每一項神通法變皆具備「四維契約」：
1. **東方仙俠表象 (Xianxia Surface)**：古典仙風道骨、符咒、飛劍、肉身法變或魔道魔相。
2. **底層文明原貌 (Underlying Origin Lore)**：四大文明本質（修仙道統 / 古代工程師 / 賽博高科技 / 克蘇魯外神）。
3. **實戰機制與戰術標籤 (Combat Role & Synergy)**：先手印記 (`PRIMER`)、引爆終結 (`DETONATOR`)、蓄力打斷 (`INTERRUPT`)、破防削韌 (`POISE_BREAK`)、防護護盾 (`BARRIER`)。
4. **代價博弈與資源交換 (Costs & Trade-offs)**：真元 (MP)、精力 (SP)、氣血 (HP) 或精神護盾 (SAN) 的戰略消耗。

### 0. 核心設計架構：【法則反應引擎 ＋ 傳奇經典名招 ＋ 四象天道領域】

2. **表層：精選「傳奇經典名牌合體技 (Signature Combos)」**：最具代表性、玩家最津津樂道的黃金拍檔，賦予獨立東方仙俠名號、專屬特效與頂級戰術收益。

   - 主角天生為四體系兼修者。在營地【靈台藏經閣】中，主角可切換裝備核心晶片，在陣法判定中自由代表任意缺失的體系，確保玩家能隨心所欲打出心儀的終結技！
2. **隊友的【道骨副修插槽 (Sub-School Socket)】**：
   - 隊友在境界突破（築基/金丹）後解鎖副修道骨插槽。例如純陽劍修可鑲嵌「克蘇魯幾丁質骨」，從而在陣法連攜中提供克蘇魯體系標籤，極大釋放隊伍搭配自由度。
