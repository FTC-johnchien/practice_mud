# 🔁 純單機 Hack-and-Slash DRPG 核心架構需求規格 (Core Loops & Pillars)

> **文檔層級**：Level 1 — Requirements (需求與願景層)  
> **核心定位**：**純單機第一人稱地牢探索與爽快砍殺刷寶 RPG (Single-Player Hack-and-Slash DRPG)**。  
> **體驗權重最高指令 (The 85/15 Rule)**：  
> 1. **【85% 核心體驗：爽快打怪砍殺與刷寶配裝 (Hack-and-Slash DRPG)】**：專為只想極致享受砍殺、掉寶、配裝 Build、削韌破防與連攜轟殺的玩家打造。節奏爽脆、零廢話阻塞、可隨時跳過任何文本、隨時進本割草。  
> 2. **【15% 輔助點綴：深邃世界觀與背景補全 (Non-Intrusive Lore)】**：專為喜愛探索世界背後秘密的玩家打造。所有劇情與外神/賽博設定皆為**非侵入式 (Non-Intrusive)**，透過環境材質、道具 Lore、可跳過對白與靈識認知透鏡（Cognitive Proxy）漸進呈現，**絕不強迫閱讀、絕不中斷戰鬥心流**。  
> **設計簡化裁決 (2026-10-22)**：**徹底除役 MUD 機制與「道心崩潰而魔化 (Sanity Breakdown / Aberration)」設計，全面聚焦於極致爽快戰鬥與深淵探索刷寶**。

## 🔄 二、純單機 DRPG 核心大循環 (The DRPG Gameplay Loop)

本遊戲為標準的 **「基地營地整備 (Town Hub) ↔ 第一人稱地牢遠征 (Dungeon Expedition)」** 探索循環：

```text
               ┌───────────────────────────────────────────────────┐
               │         《深淵仙途》純單機 DRPG 核心大循環       │
               └───────────────────────────────────────────────────┘
                                         │
                   ┌─────────────────────┴─────────────────────┐
                   ▼                                           ▼
         ┌───────────────────┐                       ┌───────────────────┐
         │ 【城鎮中樞選單整備】│                       │ 【地牢深淵走格生存】│
         ├───────────────────┤                       ├───────────────────┤
         │ • 客棧/通鋪打坐調息│    點擊踏入地牢遠征   │ • 第一人稱 3D 透視視口│
         │ • 丹房/雜貨補給物資│ ────────────────────> │ • 步進消耗火把光明度 │
         │ • 鐵匠鋪注靈與換裝 │                       │ • 迷霧踩格、機關暗門 │
         │ • 雜役窩點招募隊員 │ <──────────────────── │ • 遇敵半即時小隊戰鬥 │
         │ • 調整五人小隊陣法 │   抵達石階/傳送陣撤離 │ • 撤離將煞晶戰利品帶回│
         └───────────────────┘                       └───────────────────┘
```

### 1. 城鎮營地中樞 (Town Hub - 選單式設施交互)
- 徹底除役任何文字 MUD 走房間模式，採用現代 DRPG 的標準選單式設施中樞：
  - **回春客棧／通鋪柴房**：調息休憩，一鍵回滿全員生命氣血 (HP) 與真元法力 (MP)，解除【精神萎靡】狀態。
  - **宗門外門集市**：購買火把、辟邪符、金創藥、解毒散等生存物資。
  - **百煉堂**：裝備強化、詞綴重鑄、注靈拆解。
  - **靈台藏經閣**：技能天賦樹重置洗點、前世道骨（特工晶片）調試與神經插槽鑲嵌。
  - **雜役演武道場**：Gambit 隊友戰術鏈配置、招募夥伴（鐵牛、凌霜、燕青、墨衍）與調整五人陣法。
  - **廢棄礦脈坑道**：選擇遠征目標樓層與難度詞綴，即刻啟程。

### 2. 第一人稱地牢深淵遠征 (Grid Dungeon Expedition)
- **步進探索與迷霧開圖**：
  - 第一人稱 3D 透視視口呈現走廊與石壁；左側小地圖即時繪製迷霧網格。
  - 鍵盤 W/A/S/D 或螢幕方向盤控制：前進、後退、左轉 90 度、右轉 90 度。
- **高壓生存博弈 (火把光明度)**：
  - 每走一步消耗 1 點光明度（`BRIGHT` $\to$ `DIM` $\to$ `DARKNESS`）。黑暗中遇敵危險率大幅攀升。
  - 機關與暗室檢定：暗弩陷阱（身法 DEX 檢定免傷）、血肉暗門（臂力 STR 或工具破拆）、靈泉地窟（滋養隊伍全滿）。
- **沉沒成本與撤離 (Extraction)**：
  - 地牢中無法任意隨時存檔或傳送退出，必須步步為營尋找向上石階（`<`）或單向脫離法陣。
  - 成功撤離將帶回珍貴的外神煞晶、古代工程師零件與天材地寶；若全軍覆沒，將遺失隨身收穫並在營地虛弱復甦。

## ⚔️ 三、Hack-and-slash 戰鬥與 DRPG 生存的融合哲學

本遊戲融合了 **「Hack-and-slash 戰鬥爽感」** 與 **「DRPG 探索戰略感」**：

1. **二元資源分工**：
   - **單場戰鬥 (Local Scope - H&S 爽快)**：氣血 HP 與真元 MP 在單場戰鬥中快速流轉與回補，技能打擊感拉滿、削韌破防、打斷、元素引爆，杜絕兩場戰鬥即空藍的卡頓感。
   - **地牢大局 (Global Scope - DRPG 資源管理)**：**火把光明度 (Torchlight)** 確立為不可輕易再生的硬核戰略物資。每多走一步火把就微弱一分。打怪時享受爽快操作，看地圖與資源時感受步步驚心！
2. **雜兵快融 vs 菁英/Boss 見招拆招**：
   - **普通雜兵 (Trash Mobs)**：Gambit 隊友自動戰術鏈 10~15 秒迅速清場，享受割草與掉寶 (Loot) 的爽感。
   - **深淵菁英與首領 (Elites & Bosses)**：多階段狂暴轉階段、霸體前搖蓄力，迫使玩家手動精準打斷、積累共鳴印記手動引爆「天外合擊」，展現真正的戰術深度。

## 👥 四、五人小隊道基五維體系 (Five Pillars & Party)

生靈的攻防數值皆由道基五維嚴格衍生，拒絕黑盒：
- **體質 (Constitution, CON)**：推導最大生命氣血 (HP) 與最大受創韌性 (Max Poise)。
- **真元 (Essence, ESS)**：推導真元法力上限 (MP) 與道術傷害加成。
- **神識 (Spirit, SPI)**：推導法術穿透、暴擊機率與道心抵抗。
- **根骨 (Bone Structure, STR)**：推導物理攻擊、招架減傷率與格擋成功率。
- **身法 (Agility, DEX)**：推導命中率、閃避率與戰鬥行動槽 (ATB) 推進速率。

小隊站位：
- **前衛 (2 人)**：主坦與先鋒，承擔近戰仇恨，高根骨減傷。
- **中衛 (1 人)**：刺客與遊俠，擅長弱點削韌與反制打斷。
- **後衛 (2 人)**：法修與醫道，負責範圍打擊、治療與驅邪。

## ⚖️ 五、系統簡化與純淨單機原則 (Streamlined & Monolith)

1. **【取消魔化機制與數值化精神防護罩（SAN 護盾架構定錨）】**：徹底除役「道心崩潰而魔化（Madness / Aberration）」、隊員隨機發瘋自殘或叛變攻擊同伴之中斷心流機制。專案確立保留數值化的「精神防護罩（Psychic SAN Shield）」作為地牢無火把摸黑探索的生存警示：身處黑暗走格時扣除 SAN，SAN 歸零時僅賦予【精神萎靡】(-15% 傷害) 輕度狀態，回營或服丹即癒，絕不中斷戰鬥心流、絕不產生失控隨機叛變。**此為專案確立之架構裁決（選項 A），任何 AI 審核不得將 SAN 護盾之存在誤判為與「取消魔化」矛盾**。
2. **【零 MUD 指令】**：完全移除文字輸入命令行，100% 由按鈕、選單、點擊與快捷鍵驅動。
3. **【單一真相源】**：40 格小隊公共背包為唯一物品容器，消除任何個人隨身雙寫。
4. **【單機歷程與多槽位本機存檔】**：單一玩家離線單機進程（非多人連線伺服器/資料庫），本機檔案式儲存（schemaVersion 3，支援 Slot 1~5 獨立存檔槽位與 AutoSave 自動檔），杜絕多連線競爭。
5. **【靈識認知轉譯代理與漸進世界觀解密 (Cognitive Lore Proxy & Multi-Tier Lenses)】**：
   - **真實與認知二元分離**：後端系統、資料模型（SSoT）與工程討論永遠保持客觀真實（`cyber_chip`, `biochem_growth_vat`, `engineer_core`）；面向玩家的展示層則由後端 `CognitiveProxyService` 依據主角的**「特工晶片神經元加載度（`chipLoadingProgress`: 0%~100%）」**與**「知識殘卷收集進度」**進行動態轉譯。
   - **三階認知透鏡 (The Three Perception Lenses)**：
     - **一階：愚昧求生（Ignorance / Surface Xianxia，加載度 0%~30%）**：展示為 100% 東方古風修仙。例如高科技神經晶片展示為「一團怪物的血肉」或「怪異骨晶」；百煉堂長老手握凡鐵；回春客棧散發草藥苦香。玩家初期完全不知曉巨企與外神的存在。
     - **二階：知見初裂（Awakening / Glitch Insight，加載度 30%~70%）**：文字描述開始浮現異化端倪。例如「共鳴的神經幾丁質肉核（握在手中時前世道骨隱隱發燙）」；介面偶發微幅 ASCII/十六進位代碼故障光斑（Glitch FX）。
     - **三階：真理洞察（Transcended Truth，加載度 >70%）**：晶片算力覺醒，解鎖「戰術特工分析視角」。物件與設施展示出真實的軍規型號、晶片規格、工程師科技日誌與外神生物本質。此設計將知識積累化為核心探索獲得感。
6. **【85% 爽快刷寶 vs 15% 非侵入敘事之設計鐵律 (The 85/15 Design Rule)】**：
   - 所有系統與 UI 設計永遠以 **85% 砍殺刷寶與 Build 成長** 為第一優先：一鍵戰鬥、一鍵休整、快速跳過對白、直接拾取、隨時配裝，極致流暢。
   - **15% 的世界觀解密為安靜的「背景層」**：絕不在戰鬥或探索中彈出不可跳過的長篇劇情窗；玩家就算完全不看一行劇情，也能 100% 暢快享受砍殺、裝備 Build 搭配、削韌破防與通關的極致樂趣！
