# 🔁 純單機 Hack-and-Slash DRPG 核心架構需求規格 (Core Loops & Pillars)

> **文檔層級**：Level 1 — Requirements (需求與願景層)  
> **核心定位**：**純單機第一人稱地牢探索與爽快砍殺刷寶 RPG (Single-Player Hack-and-Slash DRPG)**。  
> **設計簡化裁決 (2026-10-22)**：**徹底除役 MUD 機制與「道心崩潰而魔化 (Sanity Breakdown / Aberration)」設計，全面聚焦於極致爽快戰鬥與深淵探索刷寶**。

## 🎯 一、專案五大核心目標 (The Five Core Pillars)

專案的所有系統設計、代碼實作與資料拓撲，無條件服務於以下 **5 個核心目標**：

| 核心目標 | 實踐路徑與體驗價值 | 涉及系統與模組 |
| :--- | :--- | :--- |
| **1. 世界觀的介紹<br>(World & Lore)** | 透過地牢第一人稱走廊石壁質地（外神卵鞘偽地殼）、情境文字日誌、NPC 交流、道具背景描述，自然展現「克蘇魯神話 × 異形強殖裝甲 × 賽博巨企掠奪 × 擬態修真」，**摒棄神經質的發狂魔化懲罰，讓玩家以清醒的理性探索宏大深邃的世界**。 | `WORLD_AND_LORE_BIBLE`, `DungeonTile`, 敘事事件日誌, 道具 Lore |
| **2. 戰鬥爽快<br>(Impactful Combat)** | 半即時 500ms ATB 時間線推進，一元一次圓桌判定，**罡氣削韌 (Poise Break) 帶來 1.5x 爆擊重創快感**，**蓄力打斷 (Combat React) 帶來見招拆招成就感**，滿屏跳動的彩色 FCT 戰況數字與受創微震反饋。 | `M3_COMBAT_ENGINE`, `CombatRules`, `DrpgCombatLoop`, `FE3_BATTLE_ARENA` |
| **3. 技能組合<br>(Skill Synergy)** | 跨隊員連攜合擊（【雙星合璧】$\to$【三才混元】$\to$【四象誅仙】$\to$【天外合擊】）、九大五行元素反應（蒸發、感電、混沌湮滅）、裂魂印記 (Primer) 與終結技 (Detonator) 瞬間引爆全屏衝擊波；配合 **Gambit 隊友自動戰術鏈** 實現神級小隊配合。 | `ComboResolver`, `party_skills.json`, `DrpgEnemyTacticsService` |
| **4. 裝備收集<br>(Loot Progression)** | 擊敗退化妖獸掉落古神血肉煞晶，搜刮工程師遺蹟獲取高頻粒子震動刃與強殖裝甲碎片，繳獲巨企特工電磁組件；**豐富的隨機詞綴、稀有度階級、鐵匠鋪注靈與詞綴比對**，驅動小隊不斷優化裝備 Build。 | `M6_ITEM_AND_ECONOMY`, 隨機詞綴生成器, 40格小隊公共行囊, 鐵匠百煉堂 |
| **5. 角色養成<br>(Character Progression)** | 深度兼顧修仙境界與科幻基因雙軌進化：**道基五維（體質/真元/神識/根骨/身法）自由加點分配**、修仙境界突破（煉氣 $\to$ 築基 $\to$ 結丹）、**主角特工晶片神經元加載度（`12%... ➔ 100%`）解鎖戰術算法**、**微量異形強殖基因覺醒**（角質骨膜防禦、高頻粒子骨刺利刃），以及 5 人小隊隊友天賦功法與專屬站位特性定制。 | `M5_SKILL_AND_PROGRESSION`, `PartyMember`, `XpProgressionService`, 特工晶片加載狀態機 |

## 🔄 二、純單機 DRPG 核心大循環 (The DRPG Gameplay Loop)

本遊戲為標準的 **「基地營地整備 (Town Hub) ↔ 第一人稱地牢遠征 (Dungeon Expedition)」** 探索循環：

```text
               ┌───────────────────────────────────────────────────┐
               │         《道祖是克蘇魯》純單機 DRPG 核心大循環       │
               └───────────────────────────────────────────────────┘
                                         │
                   ┌─────────────────────┴─────────────────────┐
                   ▼                                           ▼
         ┌───────────────────┐                       ┌───────────────────┐
         │ 【城鎮中樞選單整備】│                       │ 【地牢深淵走格生存】│
         ├───────────────────┤                       ├───────────────────┤
         │ • 客棧/通鋪打坐調息│    點擊踏入地牢遠征   │ • 第一人稱 3D 透視視口│
         │ • 丹房/雜貨補給物資│ ────────────────────> │ • 步進消耗火把光明度 │
         │ • 鐵匠鋪注靈與換裝 │                       │ • 迷霧踩格、機關暗門 │
         │ • 雜役窩點招募隊員 │ <──────────────────── │ • 遇敵半即時小隊戰鬥 │
         │ • 調整五人小隊陣法 │   抵達石階/傳送陣撤離 │ • 撤離將煞晶戰利品帶回│
         └───────────────────┘                       └───────────────────┘
```

### 1. 城鎮營地中樞 (Town Hub - 選單式設施交互)
- 徹底除役任何文字 MUD 走房間模式，採用現代 DRPG 的標準選單式設施中樞：
  - **通鋪柴房/客棧**：調息休憩，回滿全員生命氣血 (HP) 與真元法力 (MP)。
  - **宗門外門集市/雜貨鋪**：購買火把、辟邪符、金創藥、解毒散等生存物資。
  - **百煉堂/鐵匠鋪**：裝備強化、詞綴重鑄、注靈拆解。
  - **雜役窩點/酒館**：招募夥伴（鐵牛、凌霜、燕青、墨衍），配置 5 人小隊名冊與站位。
  - **礦道入口/地牢傳送門**：選擇遠征目標樓層，即刻啟程。

### 2. 第一人稱地牢深淵遠征 (Grid Dungeon Expedition)
- **步進探索與迷霧開圖**：
  - 第一人稱 3D 透視視口呈現走廊與石壁；左側小地圖即時繪製迷霧網格。
  - 鍵盤 W/A/S/D 或螢幕方向盤控制：前進、後退、左轉 90 度、右轉 90 度。
- **高壓生存博弈 (火把光明度)**：
  - 每走一步消耗 1 點光明度（`BRIGHT` $\to$ `DIM` $\to$ `DARKNESS`）。黑暗中遇敵危險率大幅攀升。
  - 機關與暗室檢定：暗弩陷阱（身法 DEX 檢定免傷）、血肉暗門（臂力 STR 或工具破拆）、靈泉地窟（滋養隊伍全滿）。
- **沉沒成本與撤離 (Extraction)**：
  - 地牢中無法任意隨時存檔或傳送退出，必須步步為營尋找向上石階（`<`）或單向脫離法陣。
  - 成功撤離將帶回珍貴的外神煞晶、古代工程師零件與天材地寶；若全軍覆沒，將遺失隨身收穫並在營地虛弱復甦。

## ⚔️ 三、Hack-and-slash 戰鬥與 DRPG 生存的融合哲學

本遊戲融合了 **「Hack-and-slash 戰鬥爽感」** 與 **「DRPG 探索戰略感」**：

1. **二元資源分工**：
   - **單場戰鬥 (Local Scope - H&S 爽快)**：氣血 HP 與真元 MP 在單場戰鬥中快速流轉與回補，技能打擊感拉滿、削韌破防、打斷、元素引爆，杜絕兩場戰鬥即空藍的卡頓感。
   - **地牢大局 (Global Scope - DRPG 資源管理)**：**火把光明度 (Torchlight)** 確立為不可輕易再生的硬核戰略物資。每多走一步火把就微弱一分。打怪時享受爽快操作，看地圖與資源時感受步步驚心！
2. **雜兵快融 vs 菁英/Boss 見招拆招**：
   - **普通雜兵 (Trash Mobs)**：Gambit 隊友自動戰術鏈 10~15 秒迅速清場，享受割草與掉寶 (Loot) 的爽感。
   - **深淵菁英與首領 (Elites & Bosses)**：多階段狂暴轉階段、霸體前搖蓄力，迫使玩家手動精準打斷、積累共鳴印記手動引爆「天外合擊」，展現真正的戰術深度。

## 👥 四、五人小隊道基五維體系 (Five Pillars & Party)

生靈的攻防數值皆由道基五維嚴格衍生，拒絕黑盒：
- **體質 (Constitution, CON)**：推導最大生命氣血 (HP) 與最大受創韌性 (Max Poise)。
- **真元 (Essence, ESS)**：推導真元法力上限 (MP) 與道術傷害加成。
- **神識 (Spirit, SPI)**：推導法術穿透、暴擊機率與道心抵抗。
- **根骨 (Bone Structure, STR)**：推導物理攻擊、招架減傷率與格擋成功率。
- **身法 (Agility, DEX)**：推導命中率、閃避率與戰鬥行動槽 (ATB) 推進速率。

小隊站位：
- **前衛 (2 人)**：主坦與先鋒，承擔近戰仇恨，高根骨減傷。
- **中衛 (1 人)**：刺客與遊俠，擅長弱點削韌與反制打斷。
- **後衛 (2 人)**：法修與醫道，負責範圍打擊、治療與驅邪。

## ⚖️ 五、系統簡化與純淨單機原則 (Streamlined & Monolith)

1. **【取消魔化機制】**：徹底除役「道心崩潰而魔化（Madness / Aberration）」負面反噬與隨機叛變，系統全面簡化，專注於戰鬥與刷寶。
2. **【零 MUD 指令】**：完全移除文字輸入命令行，100% 由按鈕、選單、點擊與快捷鍵驅動。
3. **【單一真相源】**：40 格小隊公共背包為唯一物品容器，消除任何個人隨身雙寫。
4. **【單存檔單主角】**：本地存讀檔（schemaVersion 3），杜絕多連線競爭。
