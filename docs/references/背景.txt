( 混合 克蘇魯 / 異形 / 強殖裝甲 / 多重宇宙 /  高科技的人類 / 原住民 )
宇宙 - 克蘇魯世界觀
星球 - 外神 莎布·尼古拉絲 沉眠並收縮後的卵鞘
工程師 - 異形里的造物主 (這個宇宙的高科技住民之一)
高科技的人類 - cyberpunk 文明，公司開始對其他宇宙進行商業掠奪


背景
1. 巨大的卵鞘漫無目的在宇宙飄盪不知多少年，由於巨大的質量吸引了宇宙間的灰塵與各式的元素，外表看起來就像是一個巨大的星球，直到被一個星系的恆星捕獲
2. 工程師發現了星球透過其技術開採星球的資源與能源(星球生命力)，並在星球上培養適合宇宙作戰的兵種(生物改造)，他們在生物的基因中加入了缺陷，需要由工程師開採產生的特定能源(星球生命力)來維持生命與能量
3. 這個星球所開採出來的特定能源(星球生命力)的品質與效用遠超過工程師的預期，吸引了工程師的所有部族在這個星球進行大量開採與兵種研究
4. 不知經過多久，沉眠中的星球在意識到逐漸虛弱的狀況後，向深空發出的求生訊息後進入了休眠
5. 某個瞬間由遙遠的深空的意識投來一縷的觀注，工程師們就這麼消失的無影無蹤，唯有那些不知疲倦的器材設備證明著這裡曾有過工程師的存在
6. 星球上被工程師們所創造出來的物種隨著特定能源的濃度慢慢的降低，發生了激烈的適者生存，並且為了生存與繁殖也開始進行了多樣性的組合
7. 星球上的原住民𥚢拜這些佔據地盤的物種並提供祭品以祈求對方的保護
8. 極少數的原住民能吸收並適應稀釋過的能源，並發展出了修仙文化
