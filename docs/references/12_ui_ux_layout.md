# 畫面 Layout 與前端 UI/UX 規範 (UI/UX Layout Architecture)

本文件整理自遊戲專案內 PC 桌面端優先排版、6 大核心視圖佈局、WoW + DQ/FF 混合操作介面及彈窗抽屜規範的當前實作、討論紀錄與未來架構規劃。

---

## 一、系統定位與核心理念

- **PC 優先，資訊高密度與沉浸感並存 (Desktop First)**：
  - 主要適配 1920x1080 及 1440x900 桌面顯示比例，兼顧寬高比彈性伸縮。
  - 將文字 MUD 的深度劇情沉浸與 DRPG 的空間感、戰鬥策略資訊完美整合於同一視界。
- **操作哲學：WoW 快捷鍵 + DQ/FF 階層式分類抽屜**：
  - **高頻常用操作**：仿照魔獸世界 (WoW) 快捷列，底部常駐 1~6 數字熱鍵，點擊或鍵盤即發。
  - **海量技能與道具管理**：仿照勇者鬥惡龍 (DQ) / 最終幻想 (FF) 之階層式選單抽屜，分類清晰、層級明確，徹底解決技能欄位不足問題。

---

## 二、現況分類與規劃進度

### 【已完成實作 (Implemented)】

1. **基礎前端單頁架構 (SPA Layout in `index.html`)**：
   - 包含主遊戲畫布、文字日誌終端視窗、命令輸入框、狀態監控卡片。
2. **WebSocket 即時雙向通訊**：
   - 透過 `/ws/game` 實時推送伺服器世界事件、屬性同步 (`DrpgStateDto`) 與戰鬥動作反饋。
3. **模組化彈窗系統 (Modals)**：
   - 獨立的背包物品彈窗 (`inventory-modal.js`)：支援網格展示、物品懸停 Tooltip、裝備/卸下/使用操作。
   - 獨立的夥伴陣容彈窗 (`party-modal.js`)：支援查看 4 大夥伴五維道基、職業與當前狀態。
   - 獨立的商店交易彈窗 (`shop-modal.js`)：支援購買、出售與靈石結算。
4. **ANSI 顏色解析與終端高亮**：
   - 前端內建 ANSI 轉 HTML 顏色渲染引擎，忠實呈現仙俠文字風味。

### 【架構師建議 (Recommendations)】

1. **鍵盤與滑鼠全盲操支援 (Keybinding Ergonomics)**：
   - 戰鬥介面支援純鍵盤盲操：
     - `1~6`：觸發快捷欄技能。
     - `Tab`：快速切換敵方目標。
     - `Space`：確認普通攻擊 / 對話推進。
     - `Esc`：關閉所有彈窗或取消當前技能引導。
2. **沉浸式 HUD 微交互反饋 (Micro-Interactions)**：
   - HP 低於 25% 時，畫面邊緣浮現血色心跳暈影。
   - SAN 低於 30% 時，畫面微幅抖動、日誌字體偶爾出現詭譎深淵囈語。
   - 獲得極品裝備或道核時，彈出金光流溢的領悟特效框。
3. **無障礙響應式折疊 (Responsive Breakpoints)**：
   - 當視窗寬度小於 1280px 時，右側小地圖與日誌面板自動改為側邊抽屜式折疊，確保主視圖與操作欄維持最佳比例。
